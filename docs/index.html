What the automation UI should show

1. Input form

Account ID, month/year, bill date, due date, from/to dates, bill generation IP, invoice IP, scenario type.

2. Pre-checks panel

Document existence, final bill state, test bill backup, cancelled lines, installment session, payment flags.

3. Action checklist

Step-by-step operator actions with status badges for Pending / Running / Done / Failed.

Scenario flow

  • Prepare customer and billing IDs.
  • Read sample Couchbase docs and validate current state.
  • Run test bill generation via billing API.
  • Validate output, then trigger final bill.
  • Preview invoice using invoice API.

Key UI actions

  • Load scenario
  • Run pre-checks
  • Generate test bill
  • Generate final bill
  • Create invoice preview

Backend / UI integration

The backend exposes REST endpoints that a frontend can call. The first UI version should be a simple Java-served page or a static SPA that uses these endpoints.

GET /api/v1/billing/health POST /api/v1/billing/precheck POST /api/v1/billing/scenario/run
